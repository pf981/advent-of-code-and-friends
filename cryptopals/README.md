# 🧩 Cryptopals Solutions

This repository contains **Python solutions** to the [Cryptopals](https://cryptopals.com/) cryptography challenges.

## ▶️ Usage

Run a challenge like this:

```bash
uv run set1/1.py
uv run set2/3.py
```

Replace the path with the challenge file you want to execute.
