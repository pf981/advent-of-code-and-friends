
# Everybody Codes Solutions

This project contains solutions for [Everybody Codes](https://everybody.codes/) quests and stories.

## ⚙️ Setup

This project uses uv to manage the virtual environment and dependencies.

Install uv from https://github.com/astral-sh/uv

```bash
uv sync
````

## 📥 Input files

Before running any solution or tests, **download the puzzle input files** and place them under `{quest/story}/input/`.


## 🚀 How to Run

To run a specific puzzle file using uv, execute:

```
uv run 2025/01.py
```
